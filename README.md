# oled-ldr-monitor
ESP32 OLED Display project. Interfaces an LDR light sensor on GPIO 34 and an SSD1306 128x64 I2C OLED display (SDA GPIO 21, SCL GPIO 22). Renders live light intensity readings and dynamic progress bar visualization using Adafruit GFX and SSD1306 libraries. Simulated on Wokwi prior to hardware setup.
